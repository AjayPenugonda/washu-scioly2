# WashU Science Olympiad Website

Modern, dynamic, and interactive web application for the **Washington University in St. Louis Science Olympiad (WashU SciOly)** invitational tournaments ([washuscioly.com](https://www.washuscioly.com/)).

---

## 🚀 Features

- **Collegiate Design System**: WashU Crimson (`#a51417`), Emerald Green (`#007360`), Deep Slate (`#0f172a`), and Warm Gold (`#d97706`).
- **Multi-Division Live Countdown**: Real-time ticker for Division B, Division C, and Regional tournaments with Google Calendar integration.
- **Interactive Event Catalog**: Searchable and filterable by division (B / C) and 5 Science Olympiad domains with room assignments and supervisor credits.
- **SciOly Score & Rank Simulator**: Interactive team scoring calculator with medal counts and scenario presets.
- **Danforth Campus Venue Explorer**: Interactive building details and Google MyMaps integration.
- **Complete Archive Hub**: Direct access to past exams, answer keys, results spreadsheets, and officer rosters for 2025–26, 2024–25, and 2023–24.
- **Global Command Palette (`Cmd + K`)**: Instant search across events, exams, leadership, and FAQs.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Bundler & Dev Server**: Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS Design System (no heavy frameworks)

## 📦 Getting Started

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/AjayPenugonda/washu-scioly.git
cd washu-scioly
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be created in `dist/`.
